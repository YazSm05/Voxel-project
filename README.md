# The Sandbox Voxel Workshop (Godot 4)
Moteur de voxels inspiré de *The Sandbox* avec Chunking ($16 \times 16 \times 16$), Greedy Meshing et bascule Éditeur / Exploration en temps réel.

## Contrôles
* **Clic Gauche / Droit (Mode Édition)** : Casser / Poser un cube
* **Touches 1 à 5** : Changer la couleur/matériau du bloc
* **Touche TAB** : Basculer entre le Mode Édition et le Mode Exploration (Joueur)
* **WASD / ZQSD + Espace** : Déplacer et faire sauter le personnage
